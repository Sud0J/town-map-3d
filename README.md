# Town Map 3D

Interactive low-poly 3D version of an illustrated "places in town" map: cinema, sports centre, tower, bus stop, bus station, café, bank, library, market square and park.

**Live:** https://sud0j.github.io/town-map-3d/

- Drag to rotate, scroll/pinch to zoom, right-drag to pan
- Click a building (or a chip at the top) to fly to it and read about it; Esc returns to the overview

Plain HTML + [three.js](https://threejs.org) r160 (vendored in `vendor/`, MIT). No build step, so open `index.html` through any static server.
